# Traffic Signal Console Simulation

A beginner-friendly C++ program that displays a traffic-light cycle:

1. Red - STOP (3 seconds)
2. Green - GO (3 seconds)
3. Yellow - SLOW DOWN (2 seconds)

The program asks how many cycles to run. This is an educational console
simulation, not a controller for real traffic equipment.

## Build and run on Windows

Open PowerShell in this folder and run:

```powershell
g++ -std=c++11 Traffic_Signal.cpp -o Traffic_Signal.exe
.\Traffic_Signal.exe
```
